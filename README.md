# Portfólio · Rodrigo

Site estático (HTML, CSS e JavaScript) publicado pelo GitHub Pages.

## Adicionar um projeto

1. Coloque a pasta do projeto na raiz do repositório, com um `index.html` dentro (como `landing-page-muscle-strong/`).
2. No `index.html` do portfólio, copie o bloco `<li class="work">` do primeiro projeto e troque a categoria
   (`data-cat`: `landing`, `ecommerce` ou `outros`), o número, o link, a imagem, o título, o texto e os dados.
3. A imagem de capa vai em `portfolio/img/`: uma com 1600 × 1000 px e outra com 800 × 500 px.

Os filtros e os contadores se ajustam sozinhos.

## Direitos

Fotos, textos e marcas de cada projeto pertencem aos seus donos e aparecem aqui só como amostra do trabalho.
O projeto `landing-page-muscle-strong` é uma versão de demonstração: não grava dados e não envia e-mails.
